# Automation Engineer

Harborline Manufacturing · Austin, TX · Full-time · Individual contributor

## About the role

Harborline builds electronic assemblies for industrial controls. We are hiring an automation engineer to own functional-test fixtures and the software that runs them. This is a hands-on individual contributor role working with technicians.

## Must-have requirements

- 5+ years in test automation, fixture software, or manufacturing test
- Python as a primary language for test software
- pytest or a similar Python test framework
- Hardware-in-the-loop or functional test experience on real hardware
- Modbus/TCP or serial instrument control for power supplies, DAQs, or scanners
- Linux test stations, including day-to-day shell use
- Git and CI for fixture code, such as GitLab CI
- SQL for querying test results or production data

## Nice to have

- A degree in electrical engineering or a closely related field
- Bed-of-nails or flying-probe fixture bring-up
- Electronics debug with basic bench instruments

## Tools we use

Python, pytest, Linux, Git, GitLab CI, Modbus/TCP, SQL

## How we work

You will write the fixture software, stand it up on the line, and keep the CI smoke tests honest.
